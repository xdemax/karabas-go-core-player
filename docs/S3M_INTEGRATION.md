# S3M и MikMod: варианты подключения к HW-микшеру

## Проблема

MOD/XM/IT уже используют общий `fastmix` (`src/sw/fastmix.c`). S3M сейчас идёт
через MikMod: `src/sw/mikmod_fpga.c` вызывает `VC_WriteBytes()`, а MikMod сам
микширует внутри `virtch2.c`/`virtch.c`. Наружу готовые голоса он не отдаёт.

Поэтому для S3M нельзя просто заменить `fm_mix()` — нужен отдельный слой.

## Вариант A: экспорт голосов MikMod

Идея:

- оставить MikMod как парсер/плеер;
- тикать его, но не давать ему микшировать PCM;
- вытаскивать состояние виртуальных каналов (`VINFO`/`VNF`):
  sample base, position, step, volume, pan, loop;
- конвертировать в общий `hw_voice_t` и отдавать в FPGA.

Плюсы:

- используется проверенный S3M-плеер;
- эффекты/совместимость MikMod сохраняются;
- не нужно писать новый S3M-парсер.

Минусы:

- надо вмешиваться в `mikmod/playercode/virtch2.c` или `virtch.c`;
- надо аккуратно обойти `VC_WriteBytes()`, который одновременно тикает плеер и
  микширует;
- внутренние структуры MikMod не являются стабильным API.

Нужно исследовать, есть ли чистый способ получить `VINFO` после `Player_HandleTick`
без вызова микшера. Если нет — вариант B.

## Вариант B: нативный S3M

Идея:

- написать S3M-парсер и replayer по образцу нового IT;
- использовать общий `hw_voice_t`;
- эффекты и OPL/AdLib — отдельно.

Плюсы:

- единый интерфейс для всех форматов;
- полный контроль над голосами и состоянием;
- проще интегрировать с HW-микшером.

Минусы:

- много работы;
- S3M-эффекты и совместимость;
- AdLib/OPL-инструменты всё равно требуют отдельного синтеза или fallback.

## AdLib/OPL

S3M может содержать AdLib-инструменты. Аппаратный sample-микшер их не
воспроизводит. Решение:

- детектировать AdLib при загрузке;
- для таких файлов использовать MikMod/старый путь;
- HW-микшер только для S3M на сэмплах.

## Рекомендация для первого этапа

1. Не блокировать MOD/XM/IT из-за S3M.
2. Сначала сделать HW-микшер для трёх нативных форматов.
3. Отдельно исследовать MikMod export; если он окажется слишком инвазивным —
   делать нативный S3M позже.
4. S3M с AdLib всегда оставлять на MikMod.
